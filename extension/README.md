# FeedRecall Capture

1. Open `chrome://extensions` or `edge://extensions`.
2. Enable Developer mode.
3. Choose **Load unpacked** and select this `extension` directory.
4. Open your X Likes or Bookmarks page while already signed in.
5. Scroll until the posts you want are rendered, then use **Scan tab** and **Export JSON**.

The extension reads only rendered post elements after a click. It does not read, export, or store browser cookies, passwords, private messages, or account settings.
